# 份子钱参谋

> 随礼多少、回礼怎么算、红包留言怎么写、去不了怎么随——报上城市和关系,30 秒给你区间、理由和话术。

## 为什么做它

"国庆收到 3 张婚礼请帖"年年上热搜,中秋送礼年年愁。随礼是全民刚需,但**没有任何一个工具认真回答它**:搜出来的要么是吵架帖,要么是广告。份子钱参谋把这件事标准化:城市基准 × 关系系数 × 回礼对等 × 吉利数字校验,30 秒出答案。

## 招牌输出

问"郑州,同事结婚,随多少?",得到:

- **建议金额区间**:200–400(普通/关系不错/铁子三档)
- **透明理由**:城市基准 + 关系定价 + 回礼对等,能拿去跟家人讨论
- **红包留言**:可直接复制的祝福话术
- **实用提醒**:微信红包上限 200,大额用转账备注"贺仪";不到场随六到八折,婚礼前一天转账

## 覆盖场景

婚礼 / 满月酒·百日宴 / 乔迁 / 升学宴 / 订婚 / 白事帛金(特殊规矩单独提示)/ 中秋送礼 / 伴手礼 / 探望 / 答谢;支持多请帖预算分配、婉拒请帖话术、人情账本记账。

## 有分寸的参谋

- 白事规矩地区差异最大,只给框架 + "以当地为准"
- 不做地域歧视定价,陈述习俗不评价人群
- 用户手头紧时,支持"量力而行",人情是情分不是债
- 被同事群卷着加价?它会告诉你:你的随礼只对你的关系负责
