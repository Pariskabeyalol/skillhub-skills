# 随礼行情表与计算规则

数据基准为 2024–2026 年公开讨论中的主流区间,各地习俗差异大,输出时务必带上"区间"和"以当地为准"。表内金额单位:元。

## 一、城市档基准(婚礼·普通同事关系)

| 城市档 | 普通同事/同学 | 关系好的朋友 | 铁子/近亲 |
|---|---|---|---|
| 一线(北上广深) | 400–800 | 800–1200 | 1200–2000 |
| 省会/强二线(郑州、合肥、长沙等) | 200–500 | 500–800 | 800–1500 |
| 地级市 | 200–400 | 400–600 | 600–1000 |
| 县城/乡镇农村 | 100–300 | 300–500 | 500–1000 |

地区习俗特例(陈述习俗,不带评价):

- **广东**:红包文化重"意头"轻金额,婚礼人情常见 100–200,朋友之间 200 很体面
- **江浙沪**:整体水位高,普通同事 600–1000 不罕见
- **东北/河南/山东**:300–500 是同事档主流,重"到场",人到比钱到更被看重

## 二、场合系数(在婚礼基准上浮动)

| 场合 | 相对婚礼的档位 | 说明 |
|---|---|---|
| 婚礼 | 100%(基准) | 随礼最大头 |
| 订婚 | 60–80%(部分地区只通知亲属) | 先确认是否收礼 |
| 满月酒/百日宴 | 50–70% | 同事 200 起步很常见 |
| 升学宴 | 50–70% | 近年热度下降,可随可不随的关系可以婉拒 |
| 乔迁 | 50–70% | 也可送礼不随钱 |
| 开业 | 40–60% | 花篮/礼物常可替代现金 |
| 白事(帛金) | 50–80% | **规矩特殊,见第四节** |

## 三、四条计算规则

1. **回礼对等原则(最高优先级)**:对方或对方家人当年随过你 X 元,你的底线就是 X 元;通行情义做法是 X + 100~200(抵通胀、加心意)。翻旧账要诚实:记不清就问家里长辈。
2. **关系系数**:近亲 ≈ 普通朋友 × 2;领导/下属 ≈ 普通同事(别上位加码,下属随礼给领导制造压力反而失礼)。
3. **吉利数字校验**:
   - 取双数:200/400/600/800/1000
   - 优先带 6、8:600、800、666、888
   - **避开 4** 开头或结尾(400 视地区可能犯忌,可改 388/366)
   - 部分地区流行 999(长久)、1314(一生一世)——仅限亲密关系
4. **到场加成**:人到 + 随礼 是完整人情;只随不到,按到场价打 6–8 折,转账时间选婚礼前一天,附祝福留言。

## 四、白事(帛金)特别注意

- 金额通常低于婚礼同关系档;数字规则**地区差异极大**:部分地区用单数(如 100/300/500),部分地区不忌双数——**必须提示用户以当地风俗为准,本表不给死数**
- 通用禁忌:帛金原则上**不事后补**;递白包一般不签名封口(各地不同);事后答谢宴是否参加以当地风俗为准
- 话术克制:以"节哀""保重身体"为主,不玩梗

## 五、婉拒与破局

- **就是不想随**(关系已淡、被道德绑架):合法合理。话术:「恭喜恭喜!那天正好在外地赶不回去,一点心意你千万别嫌弃」+ 小额红包(基准的 30–50%);或者干脆坦诚说明近期拮据——真朋友能理解
- **被卷着加价**:同事群里有人带节奏随 800,你不想跟——你的随礼只对**你和朋友的关系**负责,不对群里最豪的那位负责
- **记账**:建议用户开始记"人情账本"(对象/场合/金额/日期),三年后回礼对等原则就有了锚点
