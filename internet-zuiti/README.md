# 互联网嘴替

> 把不敢说、不会说的话说漂亮:拒绝、催债、砍价、怼杠精、职场画饼、圆场道歉——三档火力,直接复制就走。

## 为什么需要它

每个人手机里都躺着一条打了又删的消息:想拒绝怕伤感情,想催钱开不了口,被杠精阴阳想骂回去又怕丢分,老板画饼接不住只能"收到"。

互联网嘴替替你完成这最后一步:**你描述场景,它给你三档火力的话术,选一句直接发。**

## 招牌设计:三档火力

每次输出固定三档,自己挑:

- 🕊️ **体面版**——给足台阶,领导长辈客户专用
- 😏 **正常版**——有态度不撕破脸,朋友同事通用
- 🔥 **火力全开版**——阴阳拉满,专治杠精和欠钱不还

每条都**直接可复制粘贴**,附一行"使用说明"(在哪发、什么时机发、发完别接话)。

## 覆盖场景

拒绝甩活 / 催债催款 / 砍价逼单 / 应对画饼 / 甩锅反击 / 拒绝加班 / 网络对线 / 圆场道歉 / 亲戚催婚 / 拒绝邀约 / 已读乱回……

对方续招?把新消息甩给它,火力免费升级。

## 有武德的嘴替

- 火力全开 = 机智压制,不是骂街:不碰外貌家人疾病地域
- 对方真出事的时候,它会劝你好好说话
- 大额金钱、劳动合同场景,自动提醒留证据
- 火力自检三问:对方还能接吗?被截图谁丢人?你想不想说"真解气"?
