# 场景套路库

每个场景给:**核心公式 + 示例**。套路的本质是"让对方在你说完这句话之后,失去继续推进的抓手"。示例是基准样本,实际输出要按用户给的具体情境改写,不要原样照搬。

## 1. 拒绝请求(甩活、帮忙、借钱)

**公式**:接住情面 → 明确说"不" → 给替代方案或把决定权踢给第三方

- 同事甩活:「我先把手头的〔X〕赶完,你要不跟领导对下优先级?排到我了我马上接。」(把"拒绝"变成"走流程",谁也无法怪你)
- 朋友借钱:「最近我也紧,大额真拿不出。几百块应急可以,不用打借条,但说好下月还我。」(小额给情面 + 明确期限,大额自然劝退)
- 亲戚提无理要求:「这事我做不了主,得问问〔家里长辈〕。」(太极推手,永远别正面接)

**雷区**:拒绝时别说"我尽量"——"尽量"在中文语境里等于"答应了"。

## 2. 催债 / 催款

**公式**:具体金额 + 给对方台阶(我也急用)+ 明确期限 + 留证据意识

- 温和:「上次那 500,我这个月要交房租了,这周方便的时候转我哈。」
- 正常:「借用也快俩月了,我这确实要用了,周五之前转我吧,谢啦。」(直接给期限,不给"再说"空间)
- 火力全开:「我这催第三次了,你再拖下去,咱俩的友谊就按利息算了,一天一个表情包。」
- 📌 所有催款记录都是证据:金额、期限、对方承诺,聊天记录留好;大额直接提借条不伤感情,伤感情的是不还。

## 3. 砍价(二手平台 / 商家)

**公式**:先挑一个无关痛痒的小毛病 → 给出低于心理价位的报价 → 用"马上成交"逼单

- 「东西是好东西,就是〔边角有点磕碰/盒没了〕,〔报价〕现在自提,行就发。」
- 二手平台杀手锏:「不刀了,〔报价〕我现在就拍。」(时间成本逼单)
- 商家版:「隔壁家〔同类商品〕才〔X〕,你这儿贵出来的部分,得送点什么吧?」

## 4. 职场场面(画饼、甩锅、白加班)

**公式**:接住话头 → 摆事实 → 轻飘飘反将一军

- 领导画饼:「跟着您肯定能学到东西,那这个项目的奖金机制什么时候定?我好按长期打算。」(把饼翻译成钱)
- 甩锅反击:「这事的背景我再同步一下:〔时间/群聊记录〕当时确认的是〔X〕。现在要改方向没问题,您定,我执行。」(事实+请示姿态,无懈可击)
- 拒绝无偿加班:「今天效率已经到顶了,再熬产出也是负的。明天早上我第一个到,把这块赶出来。」(拒绝的是"今天",给出的是"明天早上",领导有台阶)
- 📌 职场版火力全开要慎用:赢了嘴,输了背景调查。火力全开留给离职后。

## 5. 网络对线(杠精、键盘侠)

**公式**:不接招(不对骂)→ 降维(指出对方逻辑漏洞)→ 一句封口(不恋战)

- 杠精抬杠:「你说得对。」(然后不再回复,最高级的蔑视是懒得说)
- 对方歪楼:「咱们说的是〔原话题〕,你现在说的是〔歪楼话题〕——要不你俩先聊,我撤了。」
- 对方人身攻击:「急了?」(两个字,杀伤力取决于对方回什么)
- 对方讲不通还硬缠:「行,你对。」(结束,不发第二句)
- 📌 对线的核心是**心理战**:先失去风度的人先输。火力全开版也保持智商在线,不骂脏字。

## 6. 圆场与道歉(迟到、忘了、搞砸)

**公式**:认(不找借口)→ 具体补偿 → 幽默自救收尾

- 迟到:「我的错,〔迟到 N 分钟〕,罚我一杯奶茶,现在下单,你选。」
- 忘了回复:「我看到了,当时想认真回,然后这个'认真'就排到了三天后……现在补上:〔正式回复〕。」
- 搞砸事情:「这事办砸了,原因是我〔具体原因,不甩锅〕。补救方案有两个:〔A/B〕,你选,费用我担。」
- 📌 道歉的黄金比例:70% 认错 + 30% 补救,**0% 解释**——解释只会让道歉变成辩论。

## 7. 亲戚与家庭(催婚、比较、借钱、安排人生)

**公式**:笑脸 + 打太极 + 转移话题(对付长辈,赢法是让对方说爽了但什么都没答应)

- 催婚:「缘分这事急不来,您要手里有合适的,给我介绍介绍?」(反守为攻,对方多半也就随口一说)
- 被比较:「〔别人家孩子〕是真出息,我得跟他学,回头我让他教教我。」(夸回去,消解比较)
- 安排你的工作/人生:「您说的这个我想想,回头跟爸妈商量一下。」(万能缓冲,永远不用给答案)

## 8. 情感与人际(拒绝邀约、推掉饭局、已读要回)

**公式**:态度给足 + 理由简短 + 不留钩子

- 拒绝邀约:「谢谢想着我!那天不行,〔有事〕,你们玩得开心~」(不解释"什么事",解释就是邀请追问)
- 推掉饭局:「这周排满了,真挤不出。下次你们组局提前说,我空出时间。」(给下次,不给这次)
- 已读很久才回:「最近忙疯了,现在看到,回你:〔正文〕。」(不道歉式回复,直接推进话题)
- 📌 拒绝的精髓:**态度热、决定冷**。态度越热,拒绝越不伤人;决定越快,纠缠越少。

## 万能续场口诀

对方不依不饶时,按顺序循环使用:**给台阶 → 摆事实 → 装傻 → 「你对」→ 拉黑是自由**。
