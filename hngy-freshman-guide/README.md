# 河南省工业学校—工校新生生存手册

> SkillHub「宝藏母校 Skill 大赛」参赛作品 · 赛道:实用刚需(内含升学彩蛋)
> 一个装进口袋的工校学长:报到、专业、升学、食堂、宿舍——问它就行。

## 这是什么

每年九月,一批十五六岁的少年第一次离开家,走进河南省工业学校(工校)的校门:报到要带什么?宿舍几个人间?手机能不能玩?中专是不是就与大学无缘了?

官方通知说得简略,班主任讲得严肃,网上的中职攻略几乎为零。这个 Skill 把一位"什么都知道的学长"装进 AI:数据驱动、随问随答,从报到清单一直讲到对口升学的备考时间线。

## 功能一览

- 🧳 **报到通关**:材料清单、军训生存、分班摸底
- 🔧 **专业图鉴**:电子商务、计算机动漫等特色专业的学习内容与实训实况
- 🎓 **升学三条路**:3+2 大专直通 / 对口升学 / 高职单招,各自适合谁、时间线怎么走
- 🍜 **食堂与周边**:校内食堂实况、文化路周边美食地图
- 🏠 **宿舍与日常**:宿舍条件、作息与手机管理真相、快递、看病
- 🚇 **交通导航**:郑州东站/郑州站/机场到校路线、两个校区怎么分
- 🏫 **校园文化**:社团、技能大赛、工校人的黑话与传说
- 💼 **实习就业**:合作企业、实习安排、"升学还是就业"怎么选

## 设计亮点

1. **为中职场景重写**:市面上的"新生指南"全是大学模板。本作按中职真实生态设计——升学三条路对比、日常管理真相、第一次离家的心理安抚,这些才是工校新生真正搜的问题。
2. **指令与数据分离,渐进式加载**:`SKILL.md` 只装行为逻辑,事实全部在 `references/` 按需读取,改数据不动指令。
3. **真实调研**:内容基于 2026 年 9 月对公开资料(学校官网、招生信息、社区讨论)的整理,查不到的明确说查不到,不凭空捏造。
4. **诚实边界**:不编造、不预测分数线、升学政策一律引导到河南省教育考试院与学校官方通知复核。

## 使用示例

**Q:中专是不是就上不了大学了?**
A:先纠正误区,再按"3+2 直通 / 对口升学 / 高职单招"三条路对比,给出本学期该做的第一步。

**Q:明天报到,要带哪些东西?**
A:按"必带证件 / 到校再买 / 从家带划算"三栏输出清单,标注需要提前办的事项。

**Q:宿舍有没有空调?手机能玩吗?**
A:给出宿舍实况与日常管理的真实情况,顺带一条工校黑话彩蛋。

## 数据来源与时效

信息整理截至 2026 年 9 月,来源包括学校官网与官方招生资料、公开社区讨论等。涉及时间、费用、政策的条目以学校及河南省教育考试院最新官方通知为准;发现过时内容欢迎反馈更新。
