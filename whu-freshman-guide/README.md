# 武汉大学—珞珈山生存手册

> SkillHub「宝藏母校 Skill 大赛」参赛作品 · 赛道:实用刚需(内含创意彩蛋)
> 一个装进口袋的武大学长:报到、选课、食堂、宿舍、黑话、猫——问它就行。

## 这是什么

每年九月,几千名新生带着同一堆问题来到珞珈山:报到要带什么?选课怎么抢?哪个食堂不踩雷?宿舍有没有独卫?凌波门怎么走?

官方通知说得抽象,学长学姐散落在各个群,网络攻略停在三年前。这个 Skill 把一位"什么都知道的学长"装进 AI:数据驱动、随问随答,还知道每一只网红猫的名字。

## 功能一览

- 🧳 **报到通关**:材料清单、军训生存指南、英语分级考、户口迁移与助学贷款实务
- 🎯 **选课攻略**:教务系统、抢课轮次与时间线、通识课推荐、GPA 制度拆解
- 🍜 **食堂红黑榜**:四大学部代表食堂、招牌菜、价格水位、校外美食地图
- 🏠 **宿舍真相**:樱园/桂园/梅园/枫园/湖滨/工部/医学部各园区实况(空调、独卫、热水、洗衣)
- 🚇 **交通导航**:三站一场到校路线(地铁几号线哪站下)、学部位置、校内交通
- 🗣️ **黑话词典**:信部、本部、梅操、奥场、樱顶、老图……听懂武大人说话
- 🐱 **校园猫图鉴**:猫协档案与网红猫出场地点
- 📸 **拍照机位** + 🗓️ **四年规划建议**(保研/考研/实习/竞赛时间节点)

## 设计亮点

1. **指令与数据分离,渐进式加载**:`SKILL.md` 只装行为逻辑(路由、个性化、边界),全部事实放在 `references/` 按需读取——回答快、不跑偏、改数据不用动指令。
2. **真实调研**:所有事实基于 2026 年 9 月对公开资料(学校官方通知、校园媒体、社区攻略)的整理与交叉印证,不凭空捏造。
3. **彩蛋传播设计**:黑话词典与猫咪图鉴是"只有武大人懂"的记忆点,天然适合截图转发到新生群,帮新生产生身份认同——这也是本作品最可能被自传播的部分。
4. **诚实边界**:不编造、不预测分数线、不碰校规红线;所有时效信息引导用户到官方渠道复核,宁可少说也不误导新生。

## 使用示例

**Q:明天报到,我到底要带哪些东西?**
A:按"必带证件 / 到校再买 / 从家带划算"三栏给出清单,标注哪些需要提前在线办理,并提醒以学院群最新通知为准。

**Q:选课马上开始了,救命?**
A:先问学部与年级,再给出抢课优先级与备选方案两档策略,附通识课口碑推荐与抢课时间线。

**Q:武大有什么好玩的?**
A:按"校外人打卡的 / 学生真常去的 / 只有武大人知道的"三层输出,顺带科普一条黑话,再抛出校园猫图鉴。

## 数据来源与时效

信息整理截至 2026 年 9 月,来源包括武汉大学官方网站与公众号发布的通知、校园媒体与学生社区公开攻略等。涉及时间、费用、政策的条目均以学校最新官方通知为准;发现过时内容欢迎反馈更新。
