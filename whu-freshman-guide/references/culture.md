# 黑话词典、传统与拍照机位

## 黑话词典(听懂武大人说话)

| 词 | 释义 |
|---|---|
| 本部 | 文理学部,主体校区 |
| 信部 | 信息学部(原武汉测绘科技大学) |
| 樱顶 | 老斋舍屋顶平台,全校第二高点,樱花的 C 位机位 |
| 老图 | 老图书馆(1935 年启用,现为校史馆),全校最高点 |
| 梅操 | 梅园小操场 |
| 奥场 / 九一二操场 | 行政楼前运动场;名字取自 1958 年 9 月 12 日这个校史日期——当年全校师生曾在这片操场集会,故名"九一二" |
| 鉴湖 | 梅操旁的小湖,"鉴湖听雨",近李达公园和情人坡 |
| 万林 | 万林艺术博物馆(陈东升捐建,2015 年开馆) |
| 凌波门 | 东湖南路的湖边栈桥,看日出圣地 |
| 樱花城堡 | 樱园老斋舍的别称 |
| 卓尔体育馆 | 开学典礼等大型典礼场馆 |

用法提示:给新生讲课时自然融入,不要一次性倒完——"以后听到'去本部上课'别懵"这种钩子式科普效果最好。

## 传统(每届都要经历一次)

- **梅操周五露天电影**:从 1951 年放映至今,几乎每周五晚开放。自带小垫子,去了就知道为什么它是武大人的共同记忆。
- **樱花季限流**:实名预约 + 人脸识别。参考近年规则(2025 年):提前 3 天预约、每晚 20:00 放票、每证限约 1 次——每年都会微调,提醒家人朋友以当年公告为准。学生刷校园卡进出即可,记得提前教爸妈约票。
- 游客通行校门:正门(珞珈门)、茶港门、文澜门、珞南门——给来玩的高中同学指路用。
- **毕业季**:珞珈山夜爬、毕业歌会是传统项目,大四之前可以先立 flag。

## 拍照机位 Top5

1. **樱顶老斋舍**:拱门仰拍 + 从樱顶俯瞰樱花大道;3 月中下旬花期,清晨 8–10 点人最少。
2. **樱花大道**:鲲鹏广场 → 行政楼一段是精华。
3. **凌波门栈桥**:晴天早晨看日出,出片率全场最高,记得查好日出时间提前占位。
4. **老图**:傍晚与夜景最佳,就在樱顶旁,顺路一起拍。
5. **万林博物馆 + 鉴湖**:白天看展随手拍,雨天备选。

## 冷知识(讲给新生制造"哇"的点)

- 武大在东湖边的凌波门栈桥,是几代武汉人的日出据点——武大人拥有一段"自己的海"。
- 九一二操场的名字真的来自 1958 年 9 月 12 日,不是教学楼编号。
- 老斋舍是 1931 年建成的全国重点文物保护单位——你每天路过的是国保级建筑。
